# Cipher - Password Intelligence Platform

A futuristic cybersecurity-themed Password Strength Analyzer built using HTML, CSS, and JavaScript.

## Features
- Real-time password strength analysis
- Password entropy calculation
- Estimated crack time detection
- Common password detection
- Strong password generator
- Copy password functionality
- Live security suggestions
- Futuristic cyberpunk UI
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- AI-assisted development
- GitHub

## Project Purpose
This project was developed to improve awareness about password security and demonstrate frontend cybersecurity dashboard design concepts.

## How to Run
1. Download the project files
2. Open `index.html` in any browser
3. Start analyzing passwords
